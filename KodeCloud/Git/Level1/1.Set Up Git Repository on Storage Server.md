Set Up Git Repository on Storage Server

The Nautilus development team has provided requirements to the DevOps team for a new application development project, 
specifically requesting the establishment of a Git repository. 
Follow the instructions below to create the Git repository on the Storage server in the Stratos DC:

1. Utilize yum to install the git package on the Storage Server.

2. Create a bare repository named /opt/ecommerce.git (ensure exact name usage).

Requirements

git package must be installed on the Storage Server using yum.

A bare Git repository must be created at the exact path /opt/ecommerce.git.

Repository must be usable by developers (permissions/ownership / optional SSH access).

Verification steps to confirm the repository was created and can be cloned/pushed to.

Solution — step-by-step (commands + explanation)

Run the following as root or with sudo on the Storage Server.

1) Install git with yum
sudo yum install -y git


Verify installation:

git --version


(You should see something like git version x.y.z.)

2) Create the bare repository at the exact path /opt/ecommerce.git

You can create it directly with git init --bare (no need to pre-create the directory):

sudo git init --bare /opt/ecommerce.git

3) Set ownership & permissions (recommended)

If you have a dedicated git user or a group of developers, adjust owner/group so they can access it. Example using git user:

Create a git service user (optional, do this if you want a central git account):

sudo useradd -m -r -s /bin/bash git


Change ownership and set group-writable + setgid so new files inherit group:

sudo chown -R git:git /opt/ecommerce.git
sudo chmod -R 2775 /opt/ecommerce.git

Verify the repository

List the repo contents (bare repo shows HEAD, refs, objects):

ls -la /opt/ecommerce.git

Check current default if it is main or master
cat /opt/news.git/HEAD

Output will look like:

ref: refs/heads/master


or

ref: refs/heads/main

To change from master → main

Update the HEAD file:

echo "ref: refs/heads/main" | sudo tee /opt/news.git/HEAD
